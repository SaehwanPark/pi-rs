# Release v0.2.2

`rupi` v0.2.2 is the installation and first-task experience release, published on
**2026-09-20**.

## Highlights

- Added checksum-verified `install.sh` for Linux/macOS and `install.ps1` for Windows.
- Added release archives for Linux x86_64, macOS Intel, macOS Apple Silicon, and Windows
  x86_64, with SHA-256 sidecars.
- Added a tag-driven GitHub Actions release workflow so future tagged releases publish
  the archives used by the installers.
- Added the Test Ledger live example: a small dependency-free Python project with an
  independent subprocess acceptance oracle and a manual walkthrough covering safe
  inspection, bounded edits, trace, and replay.
- Kept source installation available through `cargo install --path . --locked` for
  platforms without a published archive.

## Verification

The release branch was checked with:

```text
cargo fmt --all --check
cargo check -p rupi-core --all-features
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo doc --workspace --no-deps
mdbook build book
bash bench/startup.sh --json bench/results/startup-ci.json
```

The installer scripts were syntax-checked locally, the Windows installer was exercised
against a published release archive, and the Test Ledger unit and subprocess acceptance
suites passed independently.

## Upgrade note

Existing rupi sessions and configuration remain compatible. The installers only place or
replace the `rupi` executable; they do not alter `.rupi-state`, project files, or shell
configuration unless PowerShell is invoked with `-AddToPath`.
