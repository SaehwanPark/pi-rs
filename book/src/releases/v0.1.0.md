# Release v0.1.0

> Historical release notes. See [v0.2.0](v0.2.0.md) for the current release.

We are proud to announce the **v0.1.0 release of `rupi`**—a minimal, Pi-inspired coding-agent runtime implemented in Rust.

---

## What is rupi v0.1.0?

`rupi` v0.1.0 delivers a standalone, high-performance runtime for autonomous pair programming and coding agent execution. Designed from the ground up to respect honest provenance, observable execution, and low-latency interaction, `rupi` establishes a robust foundation for modern AI workflows.

---

## Core Capabilities Delivered

### 1. Minimal Core Runtime & Confinement
- **One-Shot Runner (`rupi run`)**: Execute durable coding agent turns with clear stream separation (`stdout` for assistant prose, `stderr` for transcript and diagnostics).
- **Interactive TUI (`rupi interactive`)**: High-efficiency terminal interface with multi-line editing, semantic statusline, and real-time streaming.
- **Safety Boundary**: Strict workspace confinement root (`--cwd`) and explicit refusal of unapproved mutating operations (`write`, `edit`, `exec`).

### 2. Observable Event Store & Replay
- **Canonical Event Store**: Append-only `trace.jsonl` recording typed `AgentEvent` lifecycle events.
- **Deterministic Replay (`rupi replay`)**: Re-render past sessions without re-running tools or sending network requests.
- **Event Inspection (`rupi trace`)**: View structured, chronological logs of agent turns.

### 3. Honest Reasoning Provenance
- Explicit attribution for thinking streams:
  - `[native reasoning]`: authentic model thinking tokens.
  - `[provider summary]`: provider-generated summaries of hidden reasoning.
  - `[declared]`: explicitly declared rationale.
  - `[reconstructed]`: post-hoc recovered explanations.
- Never conflates hidden chain-of-thought with exposed reasoning.

### 4. Resilient Fault Recovery
- Configurable primary and backup model providers.
- Lazy backup initialization (costs zero if unused).
- Capability pre-validation for tool calling, modalities, and context window limits.

### 5. Pi Ecosystem Compatibility
- **Skills**: Discover user and project skills with explicit `--project` trust verification.
- **Prompts**: Discover and expand parameter-substituted templates.
- **Packages**: Manifest discovery and local package installation.
- **Session Migration**: Bidirectional `import` and `export` between `rupi` and Pi JSONL formats with transparent diagnostics for non-round-trippable attributes.

### 6. Model Context Protocol (MCP) Client
- Lazy stdio worker client architecture for external tool integration.

### 7. Verified Performance Baselines
- **Warm startup**: < 1 ms (measured 0.35 ms).
- **Cold startup**: < 250 ms (measured 0.80 ms).
- **TUI keypress latency**: < 16 ms (measured < 2 ms).
