# Release v0.2.1

> Historical release notes. See [v0.2.2](v0.2.2.md) for the current release.

`rupi` v0.2.1 is the first release under the `rupi` name, published on **2026-09-20**.
The rename clarifies that this is an independent coding harness, not a Pi rewrite or Rust
port. Selected Pi ecosystem compatibility remains supported and is documented separately.

## Highlights

- Renamed the binary, Cargo workspace/packages, state directory examples, environment
  variables, repository links, CI commands, and public documentation to `rupi`.
- Refreshed the beginner guide around a real local llama.cpp endpoint:
  `127.0.0.1:8000`, model `qwen3.8-flash-next`, exposed native reasoning, and a
  262,144-token context window.
- Replaced illustrative screenshots with examples captured from the local Qwen setup.
- Curated active project documents and moved resolved audit/slice material into explicit
  archives; the archive remains read-only historical evidence.
- Removed one redundant CLI stdout assertion after reviewing the suite; boundary, failure,
  provenance, compatibility, and recovery coverage remains intact.

## Compatibility note

Existing sessions and project configuration are not silently migrated. To adopt the new
examples, change the executable name to `rupi` and update `state_dir` to `.rupi-state`.
Pi-compatible paths such as `~/.pi`, `.pi/skills`, and Pi session JSONL remain unchanged
because they belong to the upstream compatibility contract.

## Verification

The release was checked with:

```text
cargo fmt --all --check
cargo check --workspace --all-features
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo doc --workspace --no-deps
mdbook build book
```

The local-model smoke request used the configured llama.cpp endpoint and exercised the
provider example, one-shot run, trace, and replay. It did not commit machine-specific model
files, credentials, or generated session state.
