## Findings and dispositions

### P2 — Compatibility fixture assertions were Windows-dependent

**Evidence:** `tests/compat_skills.rs::every_rejection_is_reported_once_with_its_path`
compared `Path::display()` output to slash-separated literals. The baseline failure showed
`\\` on Windows. The same test suite's trusted project case depended on ambient ancestor
skill directories.

**Disposition:** Accepted and fixed. Warning paths are normalized for stable fixture
assertions, and the temporary trusted project now contains a `.git` ceiling so discovery
cannot escape the fixture into the operator's real ancestor directories. Production path
and trust semantics are unchanged.

### P2 — Windows warning policy did not pass the repository's strict clippy gate

**Evidence:** `cargo clippy --workspace --all-targets -- -D warnings` failed on the
lifetime-only `root` test field and on non-Unix builds where the Unix-only permission
parameters were unused.

**Disposition:** Accepted and fixed. The test-only lifetime holder is explicitly named
`_root`; non-Unix permission helpers consume their parameters without weakening Unix
permission enforcement.

### P1 — Extension host file URLs were not Windows-compatible

**Evidence:** Full workspace verification reached `tests/extension_host.rs` and four Node
host tests failed on Windows with `HostError::Extension { message: "Invalid URL" }`. The
current `path_to_file_url` encoded Windows backslashes but emitted `file://C:%5C...`, which
Node rejects instead of receiving an absolute `file:///C:/...` URL.

**Disposition:** Accepted and fixed in this same compatibility portability slice. The extension
host now normalizes Windows drive and extended/UNC paths into valid absolute file URLs, with
a regression test; the Node extension-host fixtures pass.

### P2 — Windows exec fixture wrote the file but returned failure

**Evidence:** Full workspace verification exposed `tests/run_cli.rs::one_turn_streams_and_persists_tools_messages_and_trace` failing only on Windows. The `set /p` command writes the expected bytes but returns status 1 at EOF, so the exec tool correctly recorded a failed command and the fixture rejected it. The same command appeared in `tests/tool_lifecycle_events.rs`.

**Disposition:** Accepted and fixed. The Windows fixture now uses a redirection form that
writes the same newline-free bytes and explicitly exits successfully; both integration
suites pass without changing exec-tool production semantics.

### P2 — Skill control-prompt path assertion was separator-sensitive

**Evidence:** Full workspace verification reached the `rupi-compat` unit suite and failed
`skill::tests::the_control_prompt_lists_the_body_of_a_skill_as_its_location` on Windows.
Fixture construction and discovery used equivalent paths with different slash spellings,
so the exact string assertion rejected a valid location.

**Disposition:** Accepted and fixed. The test compares normalized display paths while keeping
the production location unchanged, preserving the platform's usable path spelling.

### P2 — Built-in tool unit fixtures assumed POSIX path/shell output

**Evidence:** Full workspace verification failed seven `rupi-tools` unit tests on Windows:
path suffix assertions expected `/`, grep output assertions expected `/`, `pwd` resolved
to the MSYS executable under `cmd`, and the nonzero-exit fixture used POSIX `; exit` syntax.

**Disposition:** Accepted and fixed. Path/text assertions now compare normalized separators,
the working-directory fixture uses `cd` on Windows, and the nonzero-exit command uses
`exit /b` on Windows. Tool production behavior and safety boundaries are unchanged.

### Deferred — Adviser authentication

**Evidence:** `advisor_consult`, `advisor_preflight`, and `advisor_auth` could not provide a
ChatGPT audit in this environment.

**Disposition:** Deferred, not silently treated as complete. The next audit loop must retry
`advisor_consult` after adviser authentication is available, retain its complete result, and
compare it with this local audit. No completion claim is made from the local audit alone.
