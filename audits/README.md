# Audit archive

The high-severity audit cycle was completed before the `rupi` v0.2.1 release. Reports are
kept as historical evidence rather than rewritten or deleted:

- [`archive/20260916/`](archive/20260916/) — early portability and durability rounds 1–3.
- [`archive/20260919/`](archive/20260919/) — the final compatibility and recovery rounds 4–9;
  round 9 records acceptance and closes the high-severity cycle.
- [`archive/legacy/`](archive/legacy/) — superseded handoffs and reports retained from the
  earlier archive layout.

These reports describe the repository state and names at the time of each audit. They are not
current implementation or release instructions; use the canonical design, architecture,
compatibility, roadmap, and contribution documents for current work.
